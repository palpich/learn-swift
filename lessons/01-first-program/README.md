# Урок 01 — Первая программа

## Цель

Запустить файл Swift из терминала и вывести текст на экран.

## Теория

Файл `.swift` можно выполнить так:

```bash
swift start.swift
```

Функция `print` печатает значение и переводит строку:

```swift
print("Hello, Swift!")
```

Комментарии:

```swift
// одна строка
/* несколько
   строк */
```

## Задание

В `start.swift` реализуй функцию `greeting(name:)`, которая возвращает строку вида `Hello, Name!` (пробел после запятой, восклицательный знак в конце).

Код задания уже обёрнут в функцию `func greeting(name:)`. Как устроены функции, разберём в уроке 09, а пока просто напиши тело вместо `return ""`.

Запуск:

```bash
swift start.swift
```

## Как читать проверки

Внизу каждого `start.swift` есть проверки — этот код менять не нужно. После запуска для каждой проверки печатается строка:

- `✓ Anya` — проверка прошла;
- `✗ Anya: получили Hello, !, ждали Hello, Anya!` — не прошла, рядом видно, что вернул твой код и что ожидалось.

Когда всё готово, в конце появится `Урок 01 пройден!`.

## Подсказка

Собери строку через интерполяцию: `"Hello, \(name)!"`.
