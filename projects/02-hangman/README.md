# Project 02 — Hangman

После уроков 06–08.

## Цель

Угадывать слово по буквам: маска, множество ошибок, лимит жизней.

## Задание

Реализуй:

- `mask(word:guessed:)` — для каждой буквы слова покажи её, если она в `guessed`, иначе `_`. Буквы сравнивай в нижнем регистре. Между символами маски — пробел. Пример: слово `cat`, угаданы `{c}` → `"c _ _"`.
- `afterGuess(word:letter:guessed:misses:lives:)` — верни кортеж `(guessed, misses, lives, status)`, где `status` один из: `"ok"`, `"repeat"`, `"miss"`, `"win"`, `"lose"`.
  - буква уже была в угаданных или ошибках → `"repeat"` (ничего не меняй);
  - буква есть в слове → добавь в угаданные; если слово полностью открыто → `"win"`, иначе `"ok"`;
  - буквы нет → добавь в ошибки, уменьши жизни; при `lives == 0` → `"lose"`, иначе `"miss"`.

```bash
swift start.swift
swift start.swift check
```

## Подсказка

Слово и букву приводи к `lowercased()`. Победа: все буквы слова есть в `guessed`.
