# Project 04 — Notes

После урока 16.

## Цель

Мини-приложение: добавить, показать список, удалить заметку. Данные — структуры, хранение в текстовом файле рядом с программой.

## Задание

1. `struct Note` с полями `id: Int`, `text: String`.
2. `func encodeNotes(_ notes: [Note]) -> String` — каждая заметка на своей строке в формате `id|text`. Пустой список → `""`.
3. `func decodeNotes(_ data: String) -> [Note]` — обратный разбор (пустые строки игнорируй).
4. `func add(text:to:)` — новый `id` = максимум существующих + 1 (для пустого списка — `1`); верни новый массив.
5. `func remove(id:from:)` — убери заметку с таким id; если нет — верни исходный массив.

Файл по умолчанию: `notes.txt` в текущей папке.

Команды в интерактиве:

- `add text of the note`
- `list`
- `remove 2`
- `exit`

```bash
swift start.swift
swift start.swift check
```

## Подсказка

Разбор строки: `split` по `\n`, затем по `|` на две части. Первая — `Int`.
